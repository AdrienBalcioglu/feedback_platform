# Feedback Platform

A one-page tool to prioritise features with a fixed budget of points, in the spirit of the "buy a feature" exercise.

Each participant gets 100 credits and spreads them over the features they care about. Spending forces trade-offs, which a simple vote does not.

## Features

- Add features one by one, or import a list from a CSV file
- Spend credits on each feature and leave a note
- Remaining credit shown at all times
- Export the result as CSV or PDF
- Runs entirely in the browser: no server, no account, nothing is sent anywhere

## Usage

Open `index.html` in a browser. That is all.

Use **Download Template** to get the CSV format expected by the import.

## Stack

Plain HTML, CSS and JavaScript. PDF export uses [jsPDF](https://github.com/parallax/jsPDF) from a CDN.
